# Advanced Database Project – University System

A relational database project implementing a university management system in SQL Server / T-SQL, including schema design, stored procedures, triggers, and functions.

## Contents
- `UniDB.sql` – database & schema creation
- `InsertionsOfData.sql` – sample data
- `Functions.sql` / `procedures.sql` / `triggers.sql` – business logic
- `QueriesOfDB.sql` – example queries
- `Student_Prog.sql`, `Prof_load.sql` – domain-specific scripts

## How to run
Run the scripts in order (schema → data → functions/procedures/triggers → queries) in SQL Server Management Studio or a compatible client.
